# 군대 직접 조작 최소 실험

주소: `/reclaim/command/`. 기존 `/reclaim/` 전선판과 원본 `/index.html`을 수정하지 않는 별도 구현이다. 기존 아틀라스만 읽고 저장 데이터를 사용하지 않는다.

- 전장을 누른 지점 기준으로 드래그한 방향에 이동한다. 손을 떼면 멈춘다. WASD/방향키도 지원한다. 입력 취소, 창 포커스 이탈, 백그라운드 전환에서는 이동 입력을 초기화한다.
- 돌격 버튼/Space: 마지막 이동 방향으로 영웅이 짧게 진입하고 밀친다. 영웅 돌격 자체는 피해가 없다. 155 범위 안에 실제 살아 있는 병사만 참여한다. 검병은 이동 후 근접 타격, 궁수는 .35초 뒤 전방 표적에 실제 투사체를 발사한다. 6초 재사용.
- 0 / 15 / 30명 비교. 완편은 검병 20, 궁수 10이다. 영웅/적 전력과 배치는 세 모드에서 동일하다. 선택하면 전투를 재시작한다.
- 적 12명 소대 3개와 군단장 1명은 처음부터 존재한다. 방패병은 정면에서 받는 피해가 감소하고, 군단장은 붉은 원을 1.15초 예고한 뒤 현재 범위 안의 병력에 피해를 준다. 이동해서 피할 수 있다.
- 병사와 영웅 피해량을 따로 집계하고 결과 화면에 표시한다. 승리/패배를 모드별로 강제하지 않는다.

## 검증

`node territory/reclaim/command/engine.test.cjs`

동일한 단순 접근/돌격 입력을 재생한 결과: 단독은 9.5초 패배(처치 0), 15명은 27.3초 패배(적 7명 남음), 30명은 24.1초 승리. 30명 판의 피해는 병사 3,440 / 영웅 0이었다. 이는 고정 입력 비교이며 플레이어의 회피·진입 방향에 따라 달라진다.

이동/정지, 뒤따르는 병사, 돌격 거리/생존/재사용 제한, 병사 실제 피해, 방패의 정면 감소, 예고 공격 회피, 좌표 유효성 및 추가 생성 없음을 검사한다. 브라우저에서 실제 드래그·키보드 이동과 돌격 버튼을 확인했다.
