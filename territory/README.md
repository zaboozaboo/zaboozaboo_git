# 영토, 나의 영토

부하들을 이끌고 영토를 넓혀 가는 방치형 키우기 게임 프로토타입입니다. 영토에 배치한 **영웅 카드**가 건물이 되어 유닛을 계속 뽑아내고, 뽑힌 유닛들이 스타크래프트처럼 전장에서 자동으로 싸웁니다.

## 화면

시작 시 타이틀 원화와 실제 아트 로딩 진행률을 표시합니다. 새 게임은 영주 이름·외형 → 직업·스킬 → 국가 선택의 3단계로 생성하고, 저장된 게임은 타이틀의 이어하기 버튼으로 진입합니다. 메뉴 아이콘은 로컬 RPG 아트 아틀라스, 영주·영웅 카드는 캐릭터 일러스트를 사용합니다. 제작 프롬프트와 파일 목록은 `assets/ART-DIRECTION.txt`에 있습니다. 전투는 투명 전신 아틀라스를 그리는 Canvas 2D 렌더러를 사용합니다. 영주 6종·13개 영웅 병종·몬스터 20종, 지역별 전장 6종과 건물 아트를 연결했습니다. 보행·공격 반응, 피격 섬광·사망 페이드, 투사체 궤적, 범위 공격, 메테오 예고, 보스 체력바를 표시하며 전투 판정은 기존 엔진에서 처리합니다. 전투 아트 제작 프롬프트는 `assets/BATTLE-ART-DIRECTION.txt`에 있습니다.


전장이 화면을 가득 채우는 세로 구성입니다. 아군 성이 아래, 몬스터 소굴(국가전·서열전에서는 적 성)이 위에 있고 부대는 위로 진군합니다. 웨이브 진행도와 보스·국가전 남은 시간은 전장을 가리지 않도록 전장 아래 정보 줄에 표시됩니다. 아래 탭을 누르면 영토·영주·소환·전직·국가 시트가 전장 위로 올라오고, 같은 탭이나 ✕를 누르면 닫힙니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 실행돼요. 모바일 세로 화면에 맞춰 만들었습니다.

```bash
# 로컬 서버로 띄우고 싶다면
cd territory && python3 -m http.server 8000
# → http://localhost:8000
```

진행 상황은 브라우저 `localStorage`에 자동 저장됩니다. 초기화는 **영주 탭 → 데이터 초기화**에서 할 수 있어요.

## 시스템

| 시스템 | 내용 |
|---|---|
| 영주 생성 | 남/여, 직업(기사·마법사·성직자), 국가(3개) 선택. 영주도 전장에 직접 나가서 싸움 |
| 영주 스킬 | 기사 `돌격 명령`(아군 공격력·이동속도 버프), 마법사 `메테오`(광역 피해), 성직자 `성역`(전체 회복 + 피해 감소). AUTO로 자동 사용 |
| 영웅 카드 = 건물 | 카드 13종, 등급은 **일반 / 고급 / 영웅** 3단계. 배치하면 건물이 되어 일정 주기마다 부하를 **3마리 또는 5마리씩** 한꺼번에 소환. 레벨업, 중복 조각으로 ★승급. 보유 카드는 한 줄에 3~4장씩 카드 형태로 보이고, 카드를 누르면 상세 정보 |
| 영토 슬롯 | 처음 2칸, 전직할 때마다 3 → 4 → 5칸 |
| 부대 정원 | **영웅(건물)마다 정원이 다르다.** 그 건물의 부하가 정원만큼 살아 있으면 소환을 멈추고 대기. ★승급마다 +10%, `막사 확장` 강화마다 +5%. 살아남은 부대는 스테이지가 바뀌거나 보스에 도전·실패해도 그대로 유지 |
| 전직 | 직업별 4단계. 예: 기사 → 성기사 → 수호기사 → 성검왕. 영주 레벨, 스테이지, 골드 조건 필요. 단계마다 영주 외형이 확 바뀐다(갑옷·로브 색, 망토, 투구/모자/주교관, 왕관·후광, 무기, 발밑 오라·마법진, 최종 단계 날개). 체구도 단계마다 커진다 |
| 스테이지 | 적은 화면 위 **몬스터 소굴**에서 나오고, 아군은 소굴 입구 앞까지만 전진. 지역 5곳이 순환(고블린 숲 → 해골 묘지 → 오크 요새 → 얼음 협곡 → 마왕성). 5단계마다 보스(60초 제한). 실패하면 이전 단계에서 반복 사냥하고, 준비되면 `보스 도전` |
| 영지 강화 | 부대 공격력·체력, 소환 속도, 막사 확장, 성벽, 세금(골드). 강화·레벨업 버튼은 짧게 누르면 1회, 꾹 누르고 있으면 점점 빠르게 연속 강화 |
| 소환 | 💎100 1회, 💎900 10회(고급 이상 1장 확정). 확률: 일반 62% · 고급 30% · 영웅 8%, 하루 1회 무료 |
| 국가 | 아우룸(골드 +20%), 실반(체력 +20%), 이그니스(공격력 +20%). 국가 점수 1위 국가 소속이면 골드 +10% |
| 국가전 | 하루 3회. 양측 모두 개전과 동시에 첫 분대가 출격하고, 상대 건물도 내 소환 속도로 돈다. 적국 원정군과 성 공방전. 결과에 따라 국가 점수, 기여도, 💎 획득 |
| 서열전 | 하루 5회. 자국 귀족 20명 서열표에서 최대 3계단 위 상대에게 도전. 이기면 서열을 맞바꾸고, 작위(기사작 → 남작 → … → 대공)에 따라 전 능력치 보너스 |
| 방치 보상 | 접속하지 않은 시간(최대 8시간)만큼 골드 지급 |

territory/
├── index.html      화면 구성

## 전투 렌더링 검사

로컬 서버에서 `/tests/battle-render.html`을 열면 실제 저장을 읽거나 쓰지 않는 테스트 전장이 열립니다. 320/375/500px, 6개 전장, 3직업 × 남녀의 108개 조합과 8개 효과·5개 투사체의 렌더링을 검사합니다. 검사 후 지역과 직업을 바꾸어 스킬을 확인할 수 있습니다. 표시되는 렌더 시간은 해당 브라우저에서의 명령 제출 시간이며 기기별 FPS 보장은 아닙니다.

### 캐주얼 아트와 전투 안내
- `assets/casual-*.png`: 새 유닛·몬스터·건물·아이콘·타이틀. 제작 프롬프트는 `assets/CASUAL-ART-DIRECTION.txt`.
- 전장은 지역별 저밀도 색면으로 렌더링하며 유닛과 건물은 화면 비율을 유지합니다.
- `js/guidance.js`: 실제 소환 진행률, 강화 배율, 게임 배속을 반영한 출격 카운트다운 및 정원 대기 표시.
- 목표 안내는 무료 영입, 강화 비용, 반복 사냥 상태에 따라 실제 메뉴·재도전으로 연결됩니다. 공격력 안내는 해당 강화 행으로 이동합니다.
- 전투 검사에 소환 배속/강화 계산 및 재도전·영입·강화 분기 검증을 포함합니다. 플레이어 저장 데이터는 테스트에서 읽거나 수정하지 않습니다.

### 진형 로스터
전투 화면의 **진형 편성** 또는 영토 탭에서 각 부대를 전열·중열·후열에 배치하고 ↑↓로 순서를 변경합니다. 순서와 진형은 저장되며, 기존 저장은 근접 전열 / 치유 중열 / 원거리 후열로 초기화됩니다.

- 살아 있는 앞선 진형 부대가 후속 부대의 전진선을 정합니다. 원거리 부대는 사거리 안에서 사격하고, 앞선 부대가 전멸하면 보호 간격이 사라집니다. 별도 능력치 보너스는 없습니다.
- 새 전투마다 첫 소환 준비를 로스터 순서대로 0.8초 간격으로 시작합니다. 실제 출격 시각은 각 부대의 소환 주기와 배속을 반영합니다.
- 순서 변경은 부대의 진형, 소환 진행률, 기존 병력을 유지합니다. 진형 변경은 기존 병력이 걸어서 대열을 바꾸도록 합니다.
- 검증: `node territory/tests/formation.test.cjs` (프로젝트 루트). 기존 저장 마이그레이션, 소환 지연/배속, 전열 타깃, 후열 사격, 전열 붕괴, 로스터 재배치, 잠긴 슬롯을 검사합니다.

### 전장 가독성 조정
일반 유닛은 약 23px(논리 폭 320 기준), 영주는 46px로 구분합니다. 성·소환 건물을 축소하고 HUD를 압축해 전투 공간을 확보했습니다. 적은 화면 안쪽에서 등장하며 빨간 체력바와 적 인원 표시로 구분합니다. 출격 좌우 간격과 유닛 간 충돌 간격도 넓혔습니다. 렌더 검사에 500×300 전장에서 모든 몬스터의 상단 잘림 검사와 영주/병사 크기 구분 검사를 포함했습니다.

### 모바일 게임 화면 구조
- 왕국 로비: 진행 지역, 5단계 경로, 출전 부대, 다음 성장 행동, 전투 복귀/돌파 버튼. 영입·편성·왕국·성장·원정의 5개 하단 메뉴.
- 전투: 로비 메뉴를 숨기고 진행도·출격 타이머·진형/강화·스킬·배속에 집중합니다. 왕국 복귀는 진행 중인 전투를 초기화하지 않습니다.
- 로비에서도 자동 사냥은 계속되며, 보이지 않는 전투 캔버스 렌더는 생략합니다. 메뉴는 전체 높이 패널이며 전직은 로비 바로가기로 접근합니다.
- `tests/mobile-layout.html`에서 320/375/500px 폭을 확인할 수 있습니다. 테스트 캐릭터만 생성하며 저장 읽기/쓰기와 초기화를 비활성화했습니다.
- UI 참고: 탕탕특공대 공식 스토어 https://play.google.com/store/apps/details?hl=ko&id=com.dxx.firenow , 운빨존많겜 공식 스토어 https://play.google.com/store/apps/details?hl=ko&id=com.percent.aos.luckydefense . 외부 게임 이미지/코드를 프로젝트에 가져오지 않고 화면 위계와 전투 조작 영역을 참고했습니다.

### 영토 개척과 자동 주사위
- 5/10/20/30/45/60단계 보스 격파로 개척 후보지가 열린다. 기존 저장은 `maxStage`로 후보지만 복원하며 소유권은 자동 지급하지 않는다.
- 골드 지불과 시설 선택을 완료해야 소유 영토로 계산한다. 훈련장: 굴림 주기 ×0.9, 금광: 골드 배율에 +15%p. 시설 선택은 현재 영구적이다.
- 전직에는 기존 레벨·단계·골드 조건 외에 개척 영토 1/3/6곳이 필요하다. 기존 전직은 유지한다.
- 자동 주사위 기본 주기는 2초(소환 속도 강화·훈련장·게임 배속 적용). 6면을 출전 배럭에 배정하고 중복으로 생산 확률을 조절한다.
- 최근 5개 눈금을 유지한다. 5개 미만은 1명, 이후 하이카드 ×1 / 원페어·투페어 ×2 / 트리플 ×3 / 스트레이트·풀하우스 ×4 / 포카드 ×5 / 파이브카드 ×8. 무늬·플러시는 없다.
- 현재 눈금의 배럭에서만 생산한다. 빈 배럭은 0명, 정원 초과분은 소멸한다. 주사위는 정원이 차도 계속 굴린다. 편성·스테이지 전환은 기록을 초기화하지 않는다.
- 저장 항목: 개척 시설, 6면 편성, 최근 눈금, 쿨타임 진행률. 방치 중에는 주사위를 시뮬레이션하지 않고 기존 골드 보상을 적용한다.
- 검증: `node territory/tests/kingdom-dice.test.cjs`, `node territory/tests/formation.test.cjs`, `node territory/tests/lifecycle.test.cjs` (저장소 루트에서 실행). 브라우저 격리 검수: `/tests/mobile-layout.html`, `/tests/battle-render.html`.


### 왕국 순차 성장 UI (2026-10-22)
- `kingdom-ui.css`는 기존 화면 구조 위에 적용되는 공통 UI 재질·반응형 레이아웃입니다.
- 자유 선택 영지 강화 6개를 왕국 성장 경로로 교체했습니다. 각 구간은 10단계이며 계속 반복됩니다. 1장은 기본 해금이며 이후 구간은 개척 영토 1~6곳으로 열리고, 6곳 확보 후에는 계속 성장할 수 있습니다.
- 경로: 공격 → 체력 → 수입 → 공격 → 성벽 → 체력 → 생산 → 공격 → 수입 → 정원. 기존 강화 비용 공식을 사용하며, 최대치인 생산/정원 보상은 체력으로 대체합니다.
- 진행은 `S.kingdom.growth.step`에 저장합니다. 기존 저장의 강화 수치를 유지하고 신규 경로를 0부터 추가합니다. 전직/영주/영웅 성장과는 별개입니다.
- 회귀 검증: `node territory/tests/kingdom-growth.test.cjs` (저장, 영토 잠금, 비용, 중복 클릭, 기존 강화 보존 포함).

### 영주 공헌도와 레벨 돌파
- 영주 레벨은 골드 대신 `S.lord.merit` 공헌도를 소비해 한 단계씩 돌파합니다. 국가전 공헌도와는 별도입니다.
- 공헌도는 현재 스테이지 × 실제 경과 초로 누적합니다. 전투 배속의 영향을 받지 않으며 로비 자동 사냥과 최대 8시간 방치에도 적용합니다.
- 필요 공헌도는 `round(60 × 1.12^(현재 레벨 - 1))`입니다. 초과 공헌도는 다음 돌파에 사용할 수 있습니다.
- 성장 화면에 누적량, 진행 막대, 분당 획득량을 표시합니다. 기존 영주 레벨과 능력치를 유지하고 기존 저장의 공헌도는 0부터 시작합니다.
- 검증: `node territory/tests/lord-merit.test.cjs` (골드 보존, 돌파, 중복 클릭, 배속 독립 누적, 방치 중복 지급 방지, 기존 저장 호환).

### 왕국의 별과 지속 성장
- 누적 강화 횟수를 왕국 레벨로 표시하고, 10회마다 별을 하나 획득합니다. 70단계 이후에도 같은 강화 순서로 계속 성장하며 별의 최종 개수는 표시하지 않습니다.
- 별마다 영주와 병사의 공격력·체력 배율에 +5%p를 적용합니다. 3개는 ×1.15, 4개는 ×1.20입니다. 다른 강화 배율과 곱연산합니다. 회복력도 같은 계수를 적용합니다.
- 화면에는 현재 별 개수, 현재 배율, 다음 별까지 남은 강화 횟수와 다음 배율을 표시합니다. 영토 요구량은 기존대로 1~6곳이며, 6곳 이후에는 추가 영토 잠금 없이 반복 성장합니다.
- 기존 성장 단계에서 별을 산출하므로 저장을 불러와도 중복 적용되지 않습니다. 별 획득 시 출격 중인 아군도 체력 비율을 유지하며 적용합니다.
- 구간 보석 지급은 제거했습니다. 이전 버전에서 받은 보석은 유지합니다.

### 별 획득 연출
- 10번째 강화 시 성장 카드 내부에서 빛 고리·입자와 함께 별이 생성되어 별 문장으로 이동합니다. 합류 후 문장 반동과 능력치 영역의 금빛 강조, 이전→새 배율 표시가 이어집니다.
- 팝업이나 별 획득 토스트 없이 동작하며 입력을 가로채지 않습니다. 모션 감소 설정에서는 이동 없이 결과를 표시합니다.
- `/tests/mobile-layout.html`의 ‘별 획득 직전’으로 격리된 저장에서 마지막 강화 버튼을 눌러 확인할 수 있습니다.

### 고정 배치 자리
- 배치도는 전열 2·중열 1·후열 2의 다섯 자리를 항상 표시합니다. 잠긴 자리에는 필요한 전직 차수를 표시합니다.
- 기사: 후열 2 → 중열 → 전열 순서, 마법사·성직자: 전열 2 → 중열 → 후열 순서로 해금합니다. 기본 2자리, 전직마다 1자리 추가입니다.
- 위치는 슬롯에 고정되며 기존 자유 진형 저장도 해당 직업의 고정 위치로 정규화합니다. 열린 자리 사이에서 유닛 교체는 가능하며 주사위 설정은 유닛과 함께 이동합니다.
