# 영토, 나의 영토

부하들을 이끌고 영토를 넓혀 가는 방치형 키우기 게임 프로토타입입니다. 영토에 배치한 **영웅 카드**가 건물이 되어 유닛을 계속 뽑아내고, 뽑힌 유닛들이 스타크래프트처럼 전장에서 자동으로 싸웁니다.

## 화면

전장이 화면을 가득 채우는 세로 구성입니다. 아군 성이 아래, 몬스터 소굴(국가전·서열전에서는 적 성)이 위에 있고 부대는 위로 진군합니다. 아래 탭을 누르면 영토·영주·소환·전직·국가 시트가 전장 위로 올라오고, 같은 탭이나 ✕를 누르면 닫힙니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 실행돼요. 모바일 세로 화면에 맞춰 만들었습니다.

```bash
# 로컬 서버로 띄우고 싶다면
cd territory && python3 -m http.server 8000
# → http://localhost:8000
```

진행 상황은 브라우저 `localStorage`에 자동 저장됩니다. 초기화는 **영주 탭 → 데이터 초기화**에서 할 수 있어요.

## 시스템

| 시스템 | 내용 |
|---|---|
| 영주 생성 | 남/여, 직업(기사·마법사·성직자), 국가(3개) 선택. 영주도 전장에 직접 나가서 싸움 |
| 영주 스킬 | 기사 `돌격 명령`(아군 공격력·이동속도 버프), 마법사 `메테오`(광역 피해), 성직자 `성역`(전체 회복 + 피해 감소). AUTO로 자동 사용 |
| 영웅 카드 = 건물 | 카드 13종, 등급은 **일반 / 고급 / 영웅** 3단계. 배치하면 건물이 되어 일정 주기마다 부하를 **3마리 또는 5마리씩** 한꺼번에 소환. 레벨업, 중복 조각으로 ★승급 |
| 영토 슬롯 | 처음 2칸, 전직할 때마다 3 → 4 → 5칸 |
| 부대 정원 | **영웅(건물)마다 정원이 다르다.** 그 건물의 부하가 정원만큼 살아 있으면 소환을 멈추고 대기. ★승급마다 +10%, `막사 확장` 강화마다 +5%. 살아남은 부대는 스테이지가 바뀌거나 보스에 도전·실패해도 그대로 유지 |
| 전직 | 직업별 4단계. 예: 기사 → 성기사 → 수호기사 → 성검왕. 영주 레벨, 스테이지, 골드 조건 필요. 단계마다 영주 외형이 확 바뀐다(갑옷·로브 색, 망토, 투구/모자/주교관, 왕관·후광, 무기, 발밑 오라·마법진, 최종 단계 날개). 체구도 단계마다 커진다 |
| 스테이지 | 적은 화면 오른쪽 **몬스터 소굴**에서 나오고, 아군은 소굴 입구 앞까지만 전진. 지역 5곳이 순환(고블린 숲 → 해골 묘지 → 오크 요새 → 얼음 협곡 → 마왕성). 5단계마다 보스(60초 제한). 실패하면 이전 단계에서 반복 사냥하고, 준비되면 `보스 도전` |
| 영지 강화 | 부대 공격력·체력, 소환 속도, 막사 확장, 성벽, 세금(골드) |
| 소환 | 💎100 1회, 💎900 10회(고급 이상 1장 확정). 확률: 일반 62% · 고급 30% · 영웅 8%, 하루 1회 무료 |
| 국가 | 아우룸(골드 +20%), 실반(체력 +20%), 이그니스(공격력 +20%). 국가 점수 1위 국가 소속이면 골드 +10% |
| 국가전 | 하루 3회. 양측 모두 개전과 동시에 첫 분대가 출격하고, 상대 건물도 내 소환 속도로 돈다. 적국 원정군과 성 공방전. 결과에 따라 국가 점수, 기여도, 💎 획득 |
| 서열전 | 하루 5회. 자국 귀족 20명 서열표에서 최대 3계단 위 상대에게 도전. 이기면 서열을 맞바꾸고, 작위(기사작 → 남작 → … → 대공)에 따라 전 능력치 보너스 |
| 방치 보상 | 접속하지 않은 시간(최대 8시간)만큼 골드 지급 |

## 파일 구조

```
territory/
├── index.html      화면 구성
├── style.css       UI 스타일
└── js/
    ├── data.js     직업, 국가, 영웅, 몬스터, 지역, 강화 데이터
    ├── state.js    상태, 저장/불러오기, 성장 공식, 소환
    ├── battle.js   전투 엔진(소환, AI, 투사체, 스킬, 승패)
    ├── render.js   캔버스 렌더링
    ├── ui.js       탭, 모달, 국가전/서열전 진입
    └── main.js     게임 루프, 오프라인 보상
```

수치는 대부분 `data.js`와 `state.js`의 공식에 모여 있어 밸런스를 쉽게 조정할 수 있습니다.
