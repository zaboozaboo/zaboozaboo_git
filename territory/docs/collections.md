## 이전 구성 기록 — 144

던전은 소환(Hammer: 소환석·골드), 펫(Pet: 펫 소환 재료), 강화(Potion: 연구 물약) 3개만 노출·입장 가능하다. 기존 Skill/Dice 진행 기록은 저장 데이터에 보존하지만 입장과 보상 경로를 차단한다.

주사위는 포지 탈것 경제를 유지한다. 018_Summon_Rates.csv의 Mounts: ClockWinders 50개/회, 소환 레벨별 확률·요구 횟수 그대로. 033_Arena_Rewards.csv의 ClockWinders 행을 원본 수치로 포함했다. 아레나는 아직 잠겨 있으므로 실제 신규 지급은 미연결이다. 임의의 던전 지급/무료 보충은 없다. 기존 태엽 잔액은 보존한다. 주사위 능력 수치와 중복 성장은 여전히 우리 게임 초안이며 탈것 전투 스탯을 복제한 것이 아니다.

펫: 공격·보호·생산 지원 3종 + 포격·회복·충전 능력형 3종, 각 6등급. 2슬롯에 자유 배치하며 동일 ID 중복 배치는 불가. 능력형은 각자 타이머로 자동 발동한다. 별도 스킬 탭/뽑기/액티브·패시브 슬롯은 제거했다. 팝업 중에는 능력 타이머가 멈춘다. 펫 전용 아트는 아직 임시 아이콘이다.

기존 skills_r_0/1/2는 pets_r_3/4/5로 보유 수량을 그대로 변환. 기존 펫, 액티브, 패시브 순으로 최대 2개 배치를 복원하고 남은 보유분은 유지. 스킬 소환권은 ceil(잔액×100/40)으로 펫 재화에 환산한다. 이 변환은 unifiedPets 버전 플래그로 1회만 적용되며 원래 스킬 보유/장착/재화는 legacySkills에 보관한다. 기존 스킬 뽑기 횟수는 pulls.skills로 보존하며 펫 뽑기 레벨을 임의로 올리지 않는다.

뽑기 비용·확률: 원본 018_Summon_Rates.csv. 중복 요구량: 원본 021_Skill_Upgrades.csv를 공통 적용한 변형. 펫/주사위 보너스 기본 등급당 2%, 레벨당 0.5%p는 우리 게임 초안이다. 공격/체력 보너스는 이후 출격 병력에 적용한다.

## 146: 스크롤 해독과 오프라인 보상
펫 소환은 즉시 지급 대신 3개 동시 해독 자리로 이동한다. 등급별 1800/7200/14400/28800/57600/115200초는 원본 015_Eggs.csv. 절대 완료 시각을 저장하므로 오프라인에도 진행한다. 자리가 꽉 차면 재화 차감 없이 소환을 막으며 완료 후 수령 때 보유량과 중복 성장을 반영한다.

오프라인은 기존 GameplayConfig 그대로 최소 600초·최대 14400초, 골드 1/초·소환석 1/60초. 자동 지급 대신 offlinePending으로 보관하고 수집 버튼에서 한번 지급한다. 닫아도 보상이 유지되며 전장 보상 버튼에서 다시 연다. offlineAccountedAt으로 동일 부재 구간의 중복 누적을 차단한다. 기존 9999를 넘는 보상을 다음 온라인 tick에서 잘라 버리지 않도록 보존한다.
