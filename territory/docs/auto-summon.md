# 자동 소환 보관 — master-163

기준은 forge-clone-2의 현재 플레이 가능한 구현이다.
- Assets/_Project/Data/Charts/FeatureUnlock.csv: auto_forge_stack,research,6
- Assets/_Project/Domain/Rules.cs: ForgeStackUnlocked, ForgeStackCapacity=20
- Assets/_Project/Domain/AutoForgeSettings.cs: ContinueAfterMatch 기본 true
- Assets/_Project/Application/AutoForgeSession.cs: 0.9초 주기, 카드 보관/판매, 가득 참/일치 시 대기, 메뉴/비교 중 일시정지
- Docs/BalanceContract.md: 스택 용량 20은 클론의 로컬 계약이며 원본 앱에서 추출된 정확한 용량이 아님. 원본 앱 참고 설정 AutoForgeStack의 19와 혼동하지 않는다.

우리 포탈 강화 Lv.6부터 연속 보관을 해금한다. 선택한 시대만 보관하며 다른 카드는 판매한다. 연속 보관을 끄거나 Lv.6 미만이면 일치 카드 한 장에서 대기한다. 대기 중에도 자동 실행 상태를 유지하고 모든 대기 카드를 정리하면 재개한다. 수동 중지와 재화 부족은 실행을 종료한다. 메뉴나 비교 화면을 열면 소환을 멈추고 닫으면 재개한다. 용량이 찬 경우는 카드 전체를 정리할 때까지 대기한다.

최근 획득 카드부터 확인한다. 교체한 기존 유닛도 대기 카드로 남는다. 수동/자동 모두 20장 용량을 적용하며, 기존 초과 저장은 삭제하지 않고 정리 가능하게 둔다. 확인 중 자동 판매가 이전 보관 카드를 소비하지 않도록 최신 카드만 판매한 후 이전 카드를 복구한다.

이번 범위는 연속 보관이며 원본의 연구별 동시 제작 Batch 증가는 별도다. 자동 소환 한 번당 한 장/한 회분 비용으로 동작한다.

검증: Lv.5/6 경계, 20장 도달 후 추가 차감 없음, 최근 카드 우선, 자동 판매 보관 카드 보존, 메뉴/비교 대기, 정리 후 재개, 연속 보관 해제, 재화 부족 종료, 저장 복원. UI에는 연속 보관 체크와 n/20, 잠금 시 Lv.6만 표시한다.

## master-164 변경
연속 보관 체크를 제거했다. Lv.6 이상이면 자동 적용하며 기존 autoContinue 저장값은 무시한다. 한 번에 소환할 장수는 ×1/×2/×3 선택으로 표시한다. FeatureUnlock의 auto_forge_x1/2/3에 따라 최고 전선 1/36/66에서 해금되고 AutoForge 연구값의 정수부만큼 최대 장수가 추가된다. 선택값은 저장하며 현재 해금 범위로 제한한다. 0.9초마다 선택한 장수만큼 실제 소환 경로를 반복하고, 재화/용량 부족 또는 Lv.6 이전 보관 카드 발견 시 배치 중간에서 멈춘다. 생성한 장수만 비용을 차감한다. 버튼 비용은 선택 장수 기준이다. 각 카드가 기존 레벨 구간·소환 횟수 진척을 동일하게 적용받는다.
검증: 전선 35/36/65/66 경계, 3장 묶음, 재화 2개일 때 2장, 19장 보관 시 1장만 추가, Lv.5 배치 중 일치 정지, 연구 1.9의 정수부 추가.
