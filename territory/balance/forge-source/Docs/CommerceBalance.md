# 상점·진행 보상 경제 계약

## 기준과 소유권

깡보석의 일반 구매·상품별 첫 구매, 즉시 지급 묶음, 진행 후 받는 패스, 무료 수급을 구분한다. 패스와 승급을 서로의 정답으로 삼지 않는다. 수치는 현행 상품 설계이며 결제 전환율·415스테이지 도달 시간·장기 성장 속도를 실측한 결과가 아니다. 주사위 시간 가치 환율은 보상 예산과 일일 재화 상점의 주사위 판매 단가에 적용한다. 현금 교환가나 다른 시간 단축의 공통 환율을 뜻하지 않는다.

- 상품 가격·깡보석·무료 보석·무기 부가 보석: [ShopProductInfo](../Assets/_Project/Data/Charts/ShopProductInfo.csv).
- 패스·일일 상품 수량: [import_handoff.py의 project_commerce_rewards](../Tools/import_handoff.py). 원본 Handoff는 보존하고 실행 차트 `036_Progress_Pass`·`039_Economy_Deals`에 투영한다. `RewardAmount`와 `RewardDetails.Amount`를 함께 생성한다.
- 승급: [계급 보상 JSON](design/military-ranks/계급별_미션_보상표.json)과 [보상 계약](design/military-ranks/계급별_미션_보상표.md).
- 시간·던전 수급과 실제 비용: [성장 런타임](GrowthRuntime.md), [밸런스 계약](BalanceContract.md), [클라우드 계약](CloudBackend.md).

`python3 -c "import sys; sys.path.insert(0, 'Tools'); from import_handoff import project_commerce_rewards; project_commerce_rewards()"`로 상점 차트만 재생성한다. 원본 대조는 같은 호출에 `check=True`를 전달하며 `verify_baseline.py`에도 연결한다. 게시 데이터는 `build_balance_data.py`·`build_economy_data.py`로 생성한다. 변경한 실행 차트의 `balance-baseline.json` 해시는 의도한 계약 변경과 함께 갱신한다.

일반 단가는 보석당 약 $0.030~0.0333, 첫 구매는 그 절반이다. 실제 스토어 가격·원화 환산이 아니다. 2배는 상품별 최초 확정 거래에만 적용하며 무료 보석·패스·일일 상품·무기 상품에는 적용하지 않는다. 구매 이력과 영수증 재전송으로 추가 2배를 만들지 않는다.

## 성장 패스

가격은 $10이며 보통 15스테이지부터 어려움 구간을 포함한 415스테이지까지 53회차다. 구매는 유료 트랙의 추가 수령 권한만 해제한다. 무료 트랙은 그대로 받을 수 있으며 구매 즉시 전 회차를 지급하지 않는다. 회차 ID·단계·수령 비트는 유지한다.

| 전체 추가 지급 | 무료 트랙 | 유료 트랙 |
|---|---:|---:|
| 보석 | 480 | 1,600 |
| 주사위 | 1,920 | 6,400 |
| 골드 | 3,000 | 6,000 |
| 동료 소환권 | 2,200 | 4,400 |
| 스킬 소환권 | 4,600 | 9,200 |
| 탈것 소환권 | 950 | 1,900 |
| 연구 재료 | 2,500 | 5,000 |

각 회차는 트랙별 두 항목이다. 카드 위쪽은 무료 주사위·유료 보석의 기본 보상, 아래쪽은 순환 보상으로 고정한다. 무료는 주사위와 성장 묶음 또는 주요 돌파 보석, 유료는 보석과 추가 성장 묶음 또는 주사위를 지급한다. 31·51·71·91스테이지 보상은 각각 용병·스킬·연구·탈것의 첫 사용을 지원한다. 해당 기능 해금 전에는 그 재화를 지급하지 않는다. 해금 이후 네 성장 재화는 마지막 회차까지 각각 60스테이지 이내 간격으로 배치하며, 같은 재화의 지급량은 진행에 따라 감소하지 않는다. 이는 스테이지 간격 기준이며 실제 시간 간격을 보장하지 않는다.

91스테이지 이후에는 탈것·스킬·용병·연구를 번갈아 배치하고 보석 돌파 묶음으로 구간을 마무리한다. 같은 성장 재화를 연속 회차에 배치하지 않으며 재화별 최대 60스테이지 간격과 수량 비감소를 함께 지킨다. 275·395에는 탈것 150·200개, 295·355에는 연구 300·400개를 배치해 연구 재료의 연속 지급을 피한다(무료 기준). 38에는 용병 100개, 62에는 스킬 200개를 지급한다. 해금 전 다른 성장 재화를 섞을 수 없는 초반은 같은 재화의 반복을 허용한다. 수량은 각 구간의 기존 같은 재화 묶음을 기준으로 하고 소환권은 실제 사용 단위로 지급한다. 어려움 진입 211의 보석은 순환 중간에 먼저 지급하고, 마지막 구간에는 401의 스킬 묶음을 추가한 뒤 415의 보석으로 마무리한다. 무료·유료는 같은 행에서 같은 성장 재화를 보여주며, 보석 회차만 무료 보석·유료 주사위의 돌파 묶음으로 구분한다.

무료 스킬은 200→400→600개(기본 5→10→15회), 용병은 100→200→300개(1→2→3회), 탈것은 50→100→150→200개(1→2→3→4회), 연구는 100→200→300→400개다. 유료는 골드를 포함한 같은 회차 성장 묶음의 2배다. 무료 주사위는 15~85 구간 20개, 91~205 구간 30개, 211~401 구간 50개이며 최종 415에서는 100개다. 골드는 15·25스테이지에 무료 1,000·2,000개, 유료 2,000·4,000개만 지급한다. 같은 구간의 계급 과제상 주사위 Lv.4·6을 비교 기준으로 하면 무료 보상은 다음 강화 기본 비용 2,000·6,500의 50%·약 31%를 지원한다. 이는 실제 도달 레벨을 보장하는 추정이 아니다. 38 이후에는 골드를 지급하지 않는다. 골드의 반복 소비처는 주사위 강화이며, 자연 강화 대기 중 시간 보상을 상한 전에 수령하는 이용자는 다음 강화 비용보다 많은 골드를 생산할 수 있으므로 중후반 패스는 반복 소비하는 성장 재화를 지원한다. 미접속 시간·수령 상한·보석 건너뛰기에 따라 실제 골드 여유는 달라진다. 소환 확률·성장 비용·훈련 시간은 유지하며 재화 증가를 확정 능력치 상승으로 간주하지 않는다.

주요 돌파 보상은 50·125·180·211·281·341·415에 배치한다. 무료 보석은 순서대로 30·40·50·60·80·100·120개다. 유료 보석은 일반 회차에서 보통 10개·어려움 20개이며, 돌파 회차에서는 무료 보석의 정확히 2배인 60·80·100·120·160·200·240개를 지급한다. 일반 회차는 일정하게 반복하고 돌파 회차는 보석과 주사위를 함께 크게 지급해 보상 강약을 만든다. 유료 주사위는 같은 지점에서 400·600·800·900·1,000·1,200·1,500개를 지급한다. 성장 재화의 교대와 돌파 묶음의 마무리를 우선하며, 유료 주사위 간격은 패스 시작부터 30~80스테이지다. 어려움 진입과 마지막 회차를 큰 보상 지점으로 두되 주요 돌파 직후 일반 회차는 기본 묶음으로 돌아간다.

보석 예산은 일반 `GemPack2`의 800개/$25 기준으로 유료 1,600개·무료 480개다. 주사위 총량은 유료 6,400개·무료 1,920개로 독립 예산을 유지한다. 유료 패스는 보석 $50분에 주사위 설계 가치 $50분을 더하며, 이는 현금 교환가가 아니다. 성장 재화 배치는 [project_commerce_rewards](../Tools/import_handoff.py)가 소유한다. 무료 총량 확대는 용병·탈것의 긴 공백을 줄이고 후반에도 실제 소환 단위로 지급하기 위한 설계이며 특정 졸업 일수나 전투 승률을 맞춘 실측값이 아니다.

## 주사위 시간 가치와 승급

방치 보석은 0개/시간이다. 주사위는 1~12계급 연구 없음 60개/시간, 개인 연구 최대 67.5개/시간, 13~32계급 연구 없음 112.5개/시간, 개인 연구 최대 120개/시간이다. 소수는 누적 보존한다. 저장 상한·광고 배수는 별도다.

기술 연구 시간 단축은 보석 1개당 120초, 즉 1시간당 30개다. 완료 구간 주사위 120개/시간과 비교해 **보석 1개당 주사위 4개**를 보상 설계 환율로 사용한다. 따라서 $1당 보석 32개·주사위 128개다. 연구 대기 시간과 주사위 생산은 서로 다른 효용이며 실제 교환·현금 가격이나 모든 시간 단축의 공통 환율은 아니다.

승급 전체는 보석 $25분 800개와 주사위 3,200개다. 32계급·최고 레벨 920·주사위 연구 조건과 고정 능력치는 유지한다. 1~15계급의 캠페인 조건은 유지하고, 이후 기존 90~210 구간을 90~415로 늘려 5스테이지 단위 반올림한다. 마지막 과제는 어려움 205, 전체 415스테이지 클리어다. 완료 패스와 같은 진행 구간이지만 추가 레벨·연구 조건 때문에 같은 플레이 시간을 보장하지 않는다.

승급은 모든 계급에서 레벨 과제=주사위, 캠페인·주사위 레벨 과제=보석으로 고정한다. 1~8계급은 40주사위·5보석·5보석, 9~24계급은 80주사위·10보석·10보석, 25~32계급은 200주사위·25보석·25보석이다. 기존 조건만 있는 과제도 보상을 받으며, 동료·스킬·탈것 소환권 보상은 승급에서 제거한다. 이미 수령한 재화는 회수하지 않는다. 총 800보석·3,200주사위이며 보석 단위는 유지한다.

## 일일 상품

가격 $2·$7·$20·$50의 크기 0~3은 같은 종류의 기본 묶음에 각각 1·4·12·32배를 적용한다. 같은 재화의 가격당 지급량이 큰 상품에서 낮아지지 않으며, 추가 보석의 가격당 수량은 일반 깡보석보다 낮다. 서로 다른 종류의 소환·연구 재료가 같은 효용이라는 뜻은 아니다.

| 종류 | $2 기본 묶음 |
|---|---|
| 스킬 | 소환권 400 + 주사위 100 + 보석 10 |
| 동료 | 소환권 200 + 주사위 100 + 보석 10 |
| 탈것 | 소환권 100 + 주사위 100 + 보석 10 |
| 연구 | 재료 200 + 주사위 100 + 보석 10 |
| 혼합 재료 | 골드 1,000 + 스킬 200 + 동료 100 + 탈것 50 + 연구 50 + 주사위 50 |

던전 상품은 기존처럼 크기 0이 없다. $7 기본 묶음은 던전 4종 입장권 각 1개와 탈것 소환권 100개, $20은 3배, $50은 8배다. 일일 회전·3개 구매 후 다음 회차·UTC 날짜·지연 영수증의 원래 회차 정산은 기존 계약을 유지한다. 구매한 추가 입장권은 일일 기본 충전으로 지우지 않는다.

골드 단품 판매와 보석→골드 교환은 제공하지 않는다. 골드가 포함된 유료 보상은 성장 패스와 일일 혼합 재료 묶음이다.

## 일일 소환 재화 상점

[ResourceShopInfo](../Assets/_Project/Data/Charts/ResourceShopInfo.csv)가 주사위·스킬·용병·탈것·기술 물약 5종의 광고 수량, 두 젬 구매 가격·수량, 해금 기능과 한도를 소유한다. 골드·던전 열쇠·아레나 티켓·길드 물약은 제외한다. 각 행은 광고 / 소량 / 대량의 세 칸이며 해당 콘텐츠와 상점이 모두 해금되면 표시한다.

가격은 사용자 지정에 따라 다섯 재화 모두 광고 / 50보석 / 100보석의 세 칸으로 구성한다. 참조 프로젝트 `rpg-project-1/Assets/_Project/Resources/Charts/Economy/ExchangeCurrencyShopInfo.csv`의 세 칸 구조를 참조하되 구매 가격은 사용자 지정값을 사용한다. 연구 할인·상품별 첫 구매 2배는 제외하고 패키지 부가 재화는 전체 구성 가치에 포함하며, 대량 지급량은 소량의 정확히 2배로 별도 할인이 없다. 참조 프로젝트의 대량 10% 추가 지급은 적용하지 않는다.

패키지는 가격을 각 재화에 중복 배분하지 않고 **전체 구성품을 한 번씩 합산**해 비교한다. 일일 상점에서 살 수 있는 재화는 해당 판매 단가를 사용한다. 주사위는 시간 가치 기준을 판매에 적용해 1개=0.25보석(50보석 200개·100보석 400개), 스킬권 0.5보석, 용병권 1보석, 탈것권 2보석이다. 주사위 1개는 자연 수급 60~120개/시간 기준 30~60초 분량이다. 실제 지급량은 `ResourceShopInfo`가 소유한다.

기술 물약(연구 재료)은 1개=1보석으로 판매하며 광고 20개·50보석 50개·100보석 100개를 지급한다. 기술 기능과 상점이 해금되면 표시한다. 이 단가는 동일 가격·동일 부가 구성의 스킬/연구 패키지 주재료 수량(400스킬권/200기술 물약) 비율과도 일치한다. 골드·던전 입장권·무기는 정해진 단독 젬 판매가가 없으므로 임의 단가를 만들지 않고 종류·수량을 남긴다. 아래 합계는 이 비환산 구성품의 가치가 추가될 수 있는 하한이며 전체 가치를 정확히 확정한 금액은 아니다.

| 기본 현금 패키지 | 구성품별 합산(보석 상당) | 합계와 비환산 구성품 |
|---|---|---|
| 스킬 $2 | 스킬권 400×0.5 + 주사위 100×0.25 + 보석 10 | 235 |
| 용병 $2 | 용병권 200×1 + 주사위 100×0.25 + 보석 10 | 235 |
| 탈것 $2 | 탈것권 100×2 + 주사위 100×0.25 + 보석 10 | 235 |
| 연구 $2 | 연구 200×1 + 주사위 100×0.25 + 보석 10 | 235 |
| 혼합 $2 | 주사위 50×0.25 + 스킬권 200×0.5 + 용병권 100×1 + 탈것권 50×2 + 연구 50×1 | 362.5 + 골드 1,000 |
| 던전 $7 | 탈것권 100×2 + 던전 4종 입장권 각 1개 | 200 + 입장권 4개(기본 던전 클리어 시 추가 415보석 상당 + 골드 4,000) |

위 다섯 $2 계열은 $7/$20/$50에서 전체 구성이 4/12/32배, 던전은 $20/$50에서 3/8배다. 23개 구성 모두 합산액/$1을 일반 젬 상품 5종의 기본 지급량/$1과 비교한다. 일반 젬 최고 효율 33⅓보석/$1과 비교할 때 던전 이외 패키지는 합산 하한이 높다. 던전 상품은 입장권을 사용해 기본 단계 던전 4종을 클리어하는 조건으로 비교한다. `031_Dungeon_Rewards`의 기본 보상 주사위 60·스킬권 200·용병권 200·연구 재료 100개를 합산하면 415보석 상당이며 골드 4,000개도 얻는다. 따라서 $7 던전 상품은 클리어 후 615보석 상당 + 골드 4,000개이고, 입장권을 쓰지 않는 경우 즉시 지급 탈것권 200보석 상당만으로 일반 젬보다 우월하다고 주장하지 않는다. 혼합 패키지의 다섯 상점 재화는 362.5보석 상당이다.

유료 성장 패스는 보석 1,600 + 주사위 6,400×0.25 + 스킬권 9,200×0.5 + 용병권 4,400×1 + 탈것권 1,900×2 + 연구 5,000×1 = 21,000보석 상당 + 골드 6,000이다. 전 회차 진행·수령 조건부이며 즉시 지급과 같은 것으로 보지 않는다. 무기 상품 3종도 무기를 누락하지 않고 각각 60/180/300보석 + 해당 무기 1개로 비교한다. 무기의 젬 단가가 없으므로 모든 일반 젬 상품보다 우월하다는 단일 숫자는 주장하지 않는다. 일반 젬 상품은 환산 기준이고 무료 트랙·무료 상품·첫 구매 2배는 현금 기본 상품 비교에 더하지 않는다.

광고 1회는 주사위 80·스킬 40·용병 20·탈것 10·기술 물약 20개를 지급한다. 현재 유료 상점 단가로 다섯 재화 모두 20보석 상당이며 다섯 재화 모두 50보석 상품보다 지급량이 적어야 한다. 이는 상품별 환산값이며 게임 전체 광고 가치의 공통 기준이 아니다. 주사위 광고는 별도 무료 보충량으로 하루 최대 240개(자연 수급 약 2~4시간)를 유지한다. 소환권 3종은 각각 광고 5회분을 모으면 스킬 최소 5회 묶음(200개), 용병 1회(100개), 탈것 1회(50개)를 충족한다. 젬 구매에는 일일 한도가 없고 광고는 재화별 하루 3회다. UTC 자정(한국 09시)에 초기화하며 재접속·진행도 변경으로 횟수를 복구하지 않는다. 이 비교는 현행 상점의 재구매 비용과 구성품 환산 기준이며 장기 성장 속도나 체감 효용의 실측 결과가 아니다.

광고 완료 후에만 수령 명령을 전송한다. 광고 실패·취소는 보상이나 횟수를 바꾸지 않고, 같은 세션의 저장 실패 재시도는 완료한 광고를 다시 요구하지 않는다. 서버가 차트·해금·잔액·횟수를 검사하고 기존 경제 작업 ID·영수증으로 중복 지급과 응답 유실을 처리한다. 주요 재화는 서버 지갑, 주사위는 영수증 증감량을 로컬에 한 번 적용한다.

## 다른 수급·소비와 보존

주사위는 기본 제작 1회에 1개, 동료 소환은 기본 100개, 스킬은 기본 40개씩 최소 5회(200개), 탈것은 기본 50개를 소비한다. 연구 재료·골드는 실제 업그레이드 차트를 사용하며 서로 동일한 현금 단가로 간주하지 않는다.

시간 보상과 던전은 반복 성장 재화 수급이며 보석을 추가하지 않는다. 상점·패스·승급 때문에 전투 난도, 소환 확률, 업그레이드 비용을 함께 바꾸지 않는다. 최초 무료 이름 변경 이후 200보석, 길드 생성 150보석, 훈련 슬롯 확장 200/400보석, 구슬 시간 단축과 연구 시간 단축은 각 기능의 현행 비용을 유지한다. 모든 시간 단축을 동일 초/보석으로 보지 않는다. 원본에만 남은 미션·기부 가격은 활성 수급이나 소비로 집계하지 않는다.

무기 상품은 $1.99/$5.99/$9.99에 무기와 보석 60/180/300개를 한 번 지급한다. 보석 부분은 일반 깡보석과 비슷한 단가, 무기는 진행 지원 보너스로 구분하며 첫 구매 2배를 중첩하지 않는다. 무기의 실제 효용을 고정 달러로 환산하지 않는다.

이미 수령한 잔액·거래·권한·보상 수령 기록은 보존한다. 가격·상품 ID·수령 ID·저장 스키마는 바꾸지 않는다. 미수령 과제와 새 거래에 현행 수량을 적용하고 과거 지급액 차액을 소급 추가하거나 회수하지 않는다. 온라인 수량은 서버 차트가 확정하므로 클라이언트와 서버 게시 데이터를 함께 반영해야 한다. 게시 파일 생성과 운영 서버 배포는 별도 단계다.

## 검증 경계

원본 보존·행 ID·수량 필드 일치·게시 데이터 일치, 깡보석 최초/반복 구매, 일일 상품 가격당 효율, 소환권 사용 단위, 패스 권한·진행 조건·중복 수령, 저장 실패·영수증 재시도를 검증한다. `ShopTests`·`MilitaryRankTests`와 서버 `economy.test.ts`·`militaryRanks.test.ts`가 직접 경계다. 회귀 검증 통과를 장기 플레이 경제 실측이나 실제 결제 검증으로 표현하지 않는다.

주사위의 런타임 잔액은 `PlayerData.Dice`, 미수령 시간 보상은 `OfflineDice`·`OfflineDiceRemainder`가 소유한다. 저장 JSON 키 `hm`·`oh`·`ohr`와 차트·서버의 `Hammers` ID는 유지한다. `DungeonKind.Hammer`는 고대의 신전 콘텐츠 ID이며 재화 이름이 아니다. 명칭 변경은 잔액·소수 누적분·미처리 영수증의 의미나 보상량을 바꾸지 않는다.
