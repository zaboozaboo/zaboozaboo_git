# Crownward UI 마감 — Sculpted storybook

현재 채택한 방향은 기존의 둥근 3D풍 캐릭터·건물과 어울리는 입체 동화풍이다. 이번 작업은 UX만 남기는 와이어프레임 단계가 아니라 버튼·프레임·팝업·닫기·등급·주사위의 시각 마감을 포함한다. 사용자 승인 여부와 구현 완료는 별개다.

## 직접 확인한 참고 원본

- `rpg-project-1/Assets/_Project/Sprites/Main UI/button_0.png`: 넓은 둥근 외곽, 상단 하이라이트, 하단 음영. `a_bg_popup_01.png`: 두꺼운 어두운 외곽과 안쪽 표면. `button_x_04.png`: 작은 배지가 아닌 큰 X 실루엣.
- `forge-clone-2/Assets/_Project/Art/UI/fantasy-button.png`, `slot.png`, `close-button.png`: 입체 테두리, 들어간 슬롯, 큰 밝은 X.
- `forge-clone-2/Assets/_Project/UI/Styles/components/_surfaces.uss`와 `foundation/_tokens.uss`: 공통 재질과 눌림 반응, 크림·갈색·금색 계열.

참고 원본과 소스를 읽었고, 다른 프로젝트의 스크린샷을 잘라 자산으로 쓰지 않았다. 현재 그림 아틀라스는 유지하며 프레임·빛·음영은 CSS, 큰 X는 기존 SVG 경로를 사용한다. 추가 이미지 다운로드·생성은 없다.

## 유지하는 UX

- 주사위는 핵심 생산 정보. 전장 안의 충전 슬롯 가까이에 크게 표시한다.
- 전투와 UI 안전 영역을 유지한다. 이 스킨에서 캔버스 크기나 카메라를 바꾸지 않는다.
- 빈/배치/잠금 슬롯은 동일한 크기다. 등급은 이름, 프레임, 문장으로 구분한다. 선택 강조와 구분한다.
- 선택된 탭만 팝업과 같은 면으로 연결한다. 아이콘·이름을 큰 X로 가리고 재클릭하면 복원한다.
- 본문 판단 정보와 하단 주요 조작의 위치를 유지한다. 장식은 내용·터치를 가리지 않는다.

## 구현 경계

`territory/game-finish.css`는 `html[data-ui-skin="sculpted"]`에만 적용되는 마감 파일이다. 기존 UX CSS 다음에 로드한다. 같은 표면이 필요한 팝업·하단 서브메뉴·탭 접합부·X 덮개는 `--cw-paper`를 공유한다. 버튼의 얼굴/하단/테두리, 프레임 재질, 슬롯 음영, 등급 재질과 아이콘 아틀라스는 이 스킨이 소유한다. CSS의 장식 그림자는 레이아웃 공간을 늘리지 않는다.

`casual-theme.css` 등에 누적된 과거 스타일 전체를 이번에 재작성하지는 않았다. 새 마감 수정은 game-finish.css 안의 해당 컴포넌트를 수정한다. 색 수정마다 기존 CSS 뒤에 새 전역 규칙을 추가하지 않는다.

## 다른 화풍으로 바꿀 때

화풍 변경은 팔레트만 교체하는 일이 아니다. 이 작업이 모든 화풍을 미리 완성했다는 뜻도 아니다.

| 요소 | 유지할 계약 | 화풍별 교체 대상 |
|---|---|---|
| 탭/팝업 | 선택 위치, 열린 면, 큰 X, 재클릭 닫기 | 연결 경계의 그림 방식, 외곽, 표면, X 재질 |
| 영웅/슬롯 | 정원, 동일 크기, 선택·잠금·등급 식별 | 초상화, 프레임, 문장, 잠금 아트 |
| 주사위 | 눈금, 충전, 다음 굴림, 가독성 | 주사위 표면·외곽·음영·움직임 표현 |
| 아이콘 | 의미와 아틀라스 셀 매핑 | 도트/3D/애니 원본 아트. `--cw-icon-atlas`로 같은 6×5 셀 계약 사용 가능 |
| 텍스트 | 정보 순서, 비용/효과, 터치 영역 | 폰트와 렌더링. 한글 줄바꿈과 작은 화면 재검증 필요 |

도트풍은 정수 스케일·비보간 아트·각진 픽셀 외곽과 폰트까지 함께 설계한다. 애니풍은 선화·셀 음영·캐릭터와 문장 아트를 함께 바꾼다. 입체풍은 현재처럼 둥근 외곽·상부 빛·하부 두께·접촉 그림자를 쓴다. 다른 화풍을 선택하면 새로운 아트 제작은 필요하지만, 확정한 게임 논리나 화면 동선을 다시 설계할 필요는 없다.

## 검증

- 기존 19개 테스트 통과.
- 320×568, 375×720, 430×720의 전체 패널 검사: 넘침/화면 밖 주요 조작 없음.
- 세 크기 × 영입/부대/영토/성장/대전/전직 = 18개 조합에서 마감 CSS 활성/비활성의 패널·탭·버튼 영역 비교: 최대 차이 0px.
- 18개 조합 모두 큰 X 표시, 기존 탭 아이콘 가림, 재클릭 닫기, 팝업 하단과 X 덮개의 배경 일치 확인. 브라우저 오류 없음.
- 실제 전투·주사위·열린 탭·등급 카드·성장·영주 화면 육안 확인.
