# 기본 몸 디자인과 애니메이션

## 승인된 기본 베이스와 파생 제작

2026-10-24 사용자가 현재 아장아장·근접·활 애니메이션을 긍정 평가하고 기본으로 저장하라고 요청했다. 승인 스냅샷은 `territory/assets/character-base-v1/`이며 `approved.json`에 파일 해시를 기록했다. 승인된 몸·동작 원본은 보존하고 병종별 의상·장비는 별도 폴더에서 파생한다.

첫 파생 요청은 민병과 도끼다. `territory/assets/militia-v1/`에 파란 후드·튜닉·갈색 장화 프레임과 별도 도끼가 있다. 베이스 승인이 민병 결과의 승인까지 의미하지 않는다. 사용자 요청에 따라 현재 의상 제작은 허용된 단계이며, 아래 기본 몸 우선 원칙을 의상 작업 중단 요구로 오해하지 않는다.

## 현재 사용자 요청 — 디자인 유지와 베이스 동작

사용자는 `territory/assets/animation-study/character-base-design-v1.png`와 그 포즈 시안의 디자인을 유지해 걷기·몽둥이 휘두르기·활쏘기를 애니메이션으로 만들도록 요청했다. 현재 제작 기준은 이 디자인이다. 초기 character sprite base는 비율과 가독성 참고로 남긴다.

- 캐릭터는 무기를 나중에 따로 붙일 수 있는 도화지다. 몸 이미지에 무기를 굽지 않고 프레임별 손 부착점과 별도 무기 에셋을 사용한다.
- 걷기는 기존의 **아장아장**을 선호한다. 무릎을 크게 굽히거나 넓게 내딛는 걷기는 불필요하다. 짧은 다리가 몸 아래에서 작은 보폭으로 교대해야 한다. 이는 걷기에 대한 정정이며 공격 자세 전체를 곧게 펴라는 뜻이 아니다.
- 한쪽 발만 계속 내미는 것처럼 보였다는 지적이 있었다. 양쪽 접촉 자세를 실제 프레임으로 비교하고 느린 재생으로 교대를 확인한다. 눈에 보이는 차이가 없는데 프레임 번호만으로 교대한다고 설명하지 않는다.

## 핵심 목표

**옷 없이도 그 자체로 사용할 만한 캐릭터 베이스를 만든다.** 머리·몸통·손발의 형태와 자세가 실제 게임 크기에서도 명확하고, 단순한 몸 자체에 캐릭터다운 디자인이 있어야 한다. 나중에 옷과 장비를 입혀 재사용하는 것은 이 디자인을 바탕으로 하는 후속 목표다.

기존 마네킹에 의상을 덧붙이는 작업은 사용자가 중단시켰다. 기존 리그를 유지한 채 머리를 키우거나 팔다리를 줄이고 옷을 입히는 것을 새 기본 몸 디자인의 대안으로 삼지 않는다. 포즈 공유, 슬롯 분리, 접지 계산이 동작한다는 사실은 외형의 완성도를 증명하지 않는다.

## 디자인의 기준

먼저 [사용자 제공 character sprite base](references/character-sprite-base.png)를 직접 본다. 현재 기본 몸 디자인의 주 참고다. 이미지에서 머리와 몸의 비율, 짧은 팔다리, 손발의 덩어리, 몸과 팔 사이 및 두 다리 사이의 여백, 방향에 따른 얼굴과 실루엣, 자세 변화가 작은 크기에 어떻게 남는지 확인한다.

참고의 핵심은 단순한 몸만으로 완성된 캐릭터와 동작이 읽힌다는 점이다. 픽셀풍 채택이나 원본 에셋 사용을 확정한 것은 아니다. 원본을 추출·복제한 것과 새로 디자인한 결과를 구분한다. 출처와 사용권은 미확인이다.

민병 3·4번은 짧은 체형과 굽힘, 걷기를 보조적으로 참고한다. 이 민병의 옷이나 기존 마네킹 구조가 기본 몸 디자인을 결정하게 하지 않는다.

## 작업의 우선순위

- 먼저 옷과 장비 없는 기본 몸을 디자인한다. 얼굴, 머리·몸통의 연결, 손발의 크기와 모양, 팔다리의 자연스러운 굽힘을 하나의 캐릭터로 조율한다. 관절 연결용 원·캡슐·막대의 조합이 그대로 외형을 대신하지 않게 한다.
- 확대본과 실제 게임 표시 크기의 정지 모습을 함께 확인한다. 게임 렌더러의 현재 크기를 확인해 비교하며, 캔버스 내부 좌표상의 크기를 CSS 축소 후 표시 크기와 혼동하지 않는다.
- 기본 몸의 형태가 읽히는지 확인한 뒤 그 디자인을 보존하는 걷기를 만든다. 움직임으로 부족한 외형을 가리거나, 의상 시연으로 기본 몸 검토를 대체하지 않는다.
- 기본 몸이 아직 디자인 검토 단계이면 의상·장비·여러 병종으로 범위를 넓히지 않는다. 사용자가 별도로 요청하는 범위는 따른다.

프레임, 리깅, 혼합 방식은 원하는 디자인과 동작을 만드는 수단이다. 기존 코드를 재사용하기 쉽다는 이유로 디자인을 그 코드에 맞추지 않는다. 6파츠, 대기 1장·걷기 4장, 특정 리그는 고정 요구가 아니다. 제작 방식 선택을 사용자에게 반복해서 떠넘기지 않는다. 실시간 3D는 사용자가 렌더링 부담 때문에 피했던 선택이며, 2D 결과물과 혼동하지 않는다.

## 기본 몸의 확인 기준

- **옷 없는 외형:** 임시 기술 마네킹이 아니라 그대로 캐릭터로 사용할 만한 인상과 일관된 형태가 있는가.
- **작은 크기의 구분:** 머리·몸통·손발이 서로 뭉개지지 않는가. 얼굴 방향과 팔다리 위치를 관절 표시나 설명 없이 알아볼 수 있는가.
- **자세와 실루엣:** 짧은 팔다리와 굽힘이 자연스럽고, 두 발과 손의 위치가 분명한가. 확대 화면의 세부 묘사를 지워도 자세가 남는가.
- **동작 중 일관성:** 걷기를 만들 때 머리와 몸의 부피, 손발 형태가 유지되고 양발 지지가 교대하는가. 가까운 쪽·먼 쪽의 원근과 가림이 맞는가.

시각 결과를 직접 보고 판단한다. 테스트 통과, 부착점 반환, 의상 교체 성공을 디자인 완료라고 보고하지 않는다. 사용자 확인 전 시안을 승인된 기반이라고 기록하지 않는다.

## 애니메이션과 후속 재사용

걷기에서는 보폭·보행 주기·접지를 함께 확인한다. 이동 속도를 그대로 팔다리 진동수에 곱해 빠르게 떨게 하지 않는다. 프레임에는 공통 기준점과 잘리지 않는 여백을 둔다.

의상·장비 단계에 들어간 뒤에는 기본 몸 디자인을 유지하면서 동작을 공유하는지 확인한다. 손과 장비의 결합, 무기 날 방향, 신체 좌우가 프레임마다 유지돼야 한다. 사용자 승인 없이 좌우반전으로 무기 든 손이 바뀌는 문제를 감추지 않는다.

과거 실험은 비교 자료로 보존하며 임의 삭제하거나 게임에 합치지 않는다. 문서 수정 요청에서는 문서를 고치고, 제작 요청에서는 위 목표에 맞춰 제작한다. 문서 자체가 추가 작업이나 다른 대화에 메시지를 보낼 권한을 부여하지 않는다.
