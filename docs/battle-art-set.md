# 전장 아트 세트 v2

방향은 도트가 아닌 **둥근 형태의 캐주얼 일러스트**다. 현재 민병의 전신 프레임 애니메이션과 장난감 캠프를 기준으로 지형의 재질·명암·색 밀도를 맞췄다. 새 지형은 내장 이미지 생성 도구로 제작했다. forge-clone-2는 작은 병력이 보이는 빈 전투 공간과 선명한 실루엣의 참고다. 해당 프로젝트의 에셋은 복사하지 않았다.

## 현재 적용 범위

- `territory/js/battle-art-set.js`: 전장 이미지 경로, 지형 아틀라스 규격, 민병 스프라이트·무기·손 부착점의 단일 설정.
- `territory/assets/toy-battlefields-v2.png`: 숲 / 묘지 / 황무지 / 설원 / 화산 / 왕국 지형 3열 × 2행.
- 캐릭터·몬스터·건물·캠프는 기존 toy 원본을 유지한다. 전부 신규 제작한 것은 아니다.
- 민병·선봉: 기존 걷기 4프레임과 공격 6프레임을 재사용한다. 나머지 병종의 새 애니메이션을 제작한 것은 아니다.
- `territory/tests/art-set.html`: 저장을 사용하지 않는 실제 전투, 확대 걷기·공격, 캐릭터·캠프 비교 화면. 느린 재생을 제공한다.
- 이전 페인팅 지형은 비교용으로 보존하며 게임에서 로드하지 않는다.

## 지물과 이동 영역

병력은 전장 가로 좌표 80~240의 중앙 길 안에서만 이동한다. 개체 크기에 따른 발밑 여유 10~26을 추가로 확보한다. 출격·수비대 배치·추격·밀집 해소 후에도 같은 경계를 적용하며 카메라 이동과 무관하다. 현재 6종 배경의 바깥쪽 지물을 피하는 공통 통행 영역이며, 개별 나무나 바위의 픽셀별 충돌·길찾기는 아니다. `walkable-road.test.cjs`에서 지역·공성전·측면 출격·밀집을 검증한다.

## 에셋 교체 규격

`battle-art-set.js`의 `militia.clips`에서 이미지 경로와 `cols`, `rows`를 변경한다. 정수 크기의 동일 셀을 사용하며 걷기는 4개, 공격은 6개의 전신 프레임으로 맞춘다. 임의 프레임 수의 에셋이 자동 호환되는 것은 아니다. 공격의 준비→들기→정점→베기→접촉→회복 순서는 유지해야 한다. 타격은 기존 전투의 5번째 프레임 시점이며 설정 파일로 피해 시점을 변경하지 않는다.

- **무기 별도 에셋:** `weapon.file`, 손잡이 `pivot`, 끝점 `tip`, 길이 `length`와 프레임별 `grips`, `angles`를 지정한다. 좌표는 이미지/셀 대비 0~1, 각도는 라디안이다. 현재 무기는 몸 뒤에 그린다.
- **무기 포함 전신 에셋:** `weapon: null`, `trail: null`로 지정하면 별도 장비를 그리지 않는다. 전신 스프라이트를 그대로 재생한다.
- **접지:** 기본은 각 셀 아래쪽 16%의 불투명 픽셀로 발을 찾는다. 다른 여백을 쓰는 에셋은 `anchors: [{x,y,top}, ...]`를 프레임마다 지정한다. x/y는 발 기준점, top은 몸의 상단이며 모두 셀 대비 비율이다. 몸 높이 환산은 첫 프레임 기준이다.
- 이미지가 없거나 셀·발 기준점이 잘못되면 애니메이션 준비를 실패 처리하고 기존 정지 캐릭터로 전투를 그린다. 정지 이미지까지 없는 아트팩을 복원하는 기능은 아니다.
- 전신 프레임을 교체하는 구조이므로 의상을 임의로 입히거나 어떤 에셋에나 자동 리깅하는 기능은 아니다. 새로운 의상도 같은 포즈 순서와 접지 규격의 이미지가 필요하다.

## 검증

`node territory/tests/militia-combat.test.cjs`로 공격 시점·중복 타격 방지·대기·걷기·모션 감소를 검사하고, `node territory/tests/perspective.test.cjs`로 좌표 원근감을 검사한다. 브라우저에서는 아트 세트 페이지에서 양방향·사망·6공격 포즈, 6지역 × 3폭, 로딩 실패 시 정지 에셋 전환과 무기 포함 모드를 확인한다. 기존 전체 렌더 검사에는 별도 `Base countdown` 실패가 남아 있다.

지형 생성 프롬프트는 `territory/assets/TOY-SET-V2-DIRECTION.txt`에 보관한다. 이 시안은 사용자 승인된 신규 아트 규격으로 기록하지 않는다.
