# UI 배치 기준

사용자 확정 우선순위 (2026-10-25):

1. 게임의 논리 구조를 최상위로 고려한다.
2. 심미적 편안함은 색상보다 위치와 배치로 판단한다.
3. 기능 그룹화는 위 두 원칙을 충족한 뒤 편의성을 높이는 수단으로 사용한다.

전투의 핵심 인과관계는 주사위 → 모든 출전 부대 충전 → 병력 출격이다. 주사위를 보조 상태 표시로 축소하지 않는다. 주사위·충전 슬롯은 가까이 배치하고, 중앙의 전투·성·병력을 가리지 않는다. 자동 진행 정보와 직접 누르는 스킬의 역할을 구분한다.

전투 조작은 전장에 통합하고, 화면 이동 탭은 별도 영역으로 구분한다. 팝업을 열면 선택한 탭의 기존 아이콘과 글씨를 모두 가리는 큰 SVG X를 표시한다(사용자 재확정). 작은 모서리 배지로 바꾸지 않는다. 해당 탭과 팝업은 같은 배경과 이어진 테두리를 유지하고, 원래 아이콘은 팝업 제목에 표시한다. 같은 탭을 다시 누르면 닫히며 원래 아이콘과 글씨가 복원된다. 스크린샷을 잘라 X 자산으로 사용하지 않는다. 색상은 연결을 보조할 뿐 유일한 식별 수단으로 쓰지 않는다.

백판 제거 자체를 목표로 삼지 않는다. 중복 장식은 덜되, 기능 구분과 조작의 안정성을 위한 최소한의 경계는 유지한다. 실제 전투 화면과 열린 팝업을 함께 보고 작은 모바일 화면까지 검증한다.
